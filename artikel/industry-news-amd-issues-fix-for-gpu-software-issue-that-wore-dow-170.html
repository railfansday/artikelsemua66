Machines that use AMD graphics hardware such as these Radeon 6800 cards may be affected by a bug in the firm's driver software that is causing unnecessary writing to solid-state drives, which can wear them down over time.

AMD issued a software revision on Thursday to fix a driver issue that caused excessive, continuous data writes to solid-state drives across its Radeon GPU lineup.

First reported on sites including Tom’s Hardware and Neowin, the bug was traced to two pieces of software: AMD External Events Client Module and Utility, known as atieclxx.exe or atiesrxx.exe under Windows processes. The background service handles monitoring functions, but as some people have noticed, it’s also writing a large amount of data to SSDs, as much as 432GB in 24 hours, according to Neowin.

The optional upgrade is available on AMD’s website as Adrenalin Edition 26.11.1. In the notes for the update, AMD remarked the new software addresses “excessive system-drive writes while the system is idle on Radeon RX 7000 series graphics products and above” and “excessive system-drive writes while moving or resizing application windows.”.

According to recent reports, this excessive data writing is a concern because it can accelerate the wear and tear on an SSD, potentially shortening its lifespan. According to PC Gamer, that could mean losing 1% of the drive’s health in just a month. As one Reddit poster pointed out, this is not a fresh bug and, in one case, may have caused SSD degradation for nearly a year and a half.

Organization staffers were previously posting on Reddit that a fix was coming.

The cost of SSDs has spiked dramatically in the last couple of years, so it could be an expensive problem to fix if it causes significant wear on a drive.

According to recent reports, the same Reddit users who helped uncover the bug and spread the word have a few ideas for how to prevent this if you haven’t updated to the newly introduced software. First, check the Windows Resource Monitor (you can access it by pressing Windows key + R and typing “resmon”) and look in the Disk tab to see if you’re experiencing excessive writing to your SSD from either atieclxx.exe or atiesrxx.exe processes.

Some who are seeing this are disabling the External Events software entirely. You can do that in Windows by typing Windows key + R and entering “services.msc.” Once there, you can look for the AMD External Events Utility, open its Properties and set Startup Type to Disabled. That will keep it from starting up automatically when you reboot. You can also stop the process while you’re there for the current session. You’ll want to restart your computer after this change.

It has been revealed that keep in mind that disabling the software could affect some display functions and game performance. Others have tried disabling a Resizable Bar, or ReBAR, a PCI Express process for accessing video card memory. Some have switched to alternative AMD drivers that are only compatible with AMD chipsets, not those with Intel or other chipset motherboards.

These options may be a temporary fix if you’re unable to install the latest software, but be warned: Using any of those methods carries the risk of breaking other functions on your machine, so make sure your system has a recent restore point.
