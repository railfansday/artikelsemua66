Cloudflare wants AI agents to search websites, not crawl them

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Cloudflare’s illustration shows robots searching a website through a magnifying glass, above an on/off switch.

In a recent development, cloudflare has debuted Search for Agents in beta for all customers, including free ones. Switching it on indexes a site and adds a search endpoint on its own domain, advertised on every page, so AI agents can search the site instead of crawling it page by page.

Cloudflare has launched a switch that turns a website on its network into a search engine for AI agents, the firm mentioned on Wednesday. Search for Agents is in beta and open to every customer, including those on the free plan.

Sources indicate that once it is on, Cloudflare crawls and indexes the site, then puts a search endpoint at a standard address on the site’s own domain. Every page also carries hidden tags telling visiting agents the search exists. That way, agents can search the site instead of crawling it page by page.

The search returns matching text from the site, not an AI-written answer. Cloudflare says the agent already has its own AI model, so it only needs the source material.

It has been revealed that site owners keep their existing defences. Agents still face each site’s bot settings and firewall rules, which Cloudflare has tightened against AI crawlers this year. It has also worked with OpenAI to help ChatGPT find latest pages faster.

According to recent reports, the launch is Cloudflare’s latest move to shape how agents use the web. In August it released Kitesurf, a browser for AI agents.

Daily requests from AI agents on its network grew over 1,700% in a year, Cloudflare stated in October. Chief executive Matthew Prince has said bot traffic could reach 1,000 times human levels.

It has been revealed that use is billed under Cloudflare’s AI Search pricing, which starts charging on December 1, with some usage included each month. Free aims come with tighter limits.
