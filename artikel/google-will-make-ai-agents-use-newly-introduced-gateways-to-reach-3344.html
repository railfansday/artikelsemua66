Google will make AI agents use newly introduced gateways to reach Gmail and Drive

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Google has made its Workspace MCP servers and CLI generally available and notes AI agents must use them instead of existing REST APIs from February 1, 2027. Every call is checked against manufacturer policies, sensitive actions need user confirmation, and a latest addendum bars AI tools from training on Workspace data.

Google will require AI agents to reach Gmail, Drive and other Workspace apps through new, dedicated gateways, it said on Tuesday. Regular apps can keep using Workspace’s existing APIs, but agents must switch by February 1, 2027.

Sources indicate that the gateways are Workspace MCP servers, which use a common standard for linking AI tools to apps, and a command-line tool. Both are now generally available. Google put an early CLI version on GitHub in March.

Google indicates its APIs were built for apps that work at human speed, where a valid login meant the user wanted the action. Agents act on their own at machine speed. So every request now gets checked against company permissions and data-loss rules.

In a recent development, agents can draft emails and summarise documents on their own. But they need a person’s sign-off before sending email, changing Drive sharing or making bulk edits.

In a recent development, each agent also needs its own sign-in ID with tight limits and usage quotas. Google already gives its Gemini coworker agents their own accounts. It will begin billing for that usage on April 1, 2027.

In a recent development, A new AI Tools Addendum adds rules on data. AI tools cannot use Workspace data to train models or build rival services, and cannot scrape it. They must also delete it when a user disconnects.

Google also tells developers to screen for prompt injection, hidden commands in emails or files that can hijack AI agents. Some controls are still to come, including letting users see and revoke agents’ access themselves.

Other firms are drawing lines too. In October, Charles Schwab said it blocks outside agents from moving client money.
