Recent findings suggest that but Chrome’s default experience could use some improvement (as is the case with most software). Where do you start? I’m going to address what I believe are the most notable changes to make in Chrome, so I won’t talk about appearance, tabs, or speed. This is mostly about privacy, security, and minimizing general annoyances, so you can get the best experience with Google’s browser.

It has been revealed that the single most key thing you can do in any browser is to enable the best protection it offers for your needs. In Chrome, this all starts with Enhanced Protection. Note: Enhanced Protection is typically the default, but this setting is so important that you should check to ensure it’s enabled.

There is one thing to keep in mind about Enhanced Protection: you lose some privacy because more data is sent to Google. With Enhanced Protection enabled, you share what you download and view with Google. If privacy is as important to you as important security, you could drop down to Standard Protection, because it’s still going to protect you against most threats.

This setting is configured in Chrome > Settings > Privacy and security > Security.

Recent findings suggest that yes, this one’s an inconvenience, but a web browser’s built-in password manager is simply not as safe as a dedicated password manager like KeePassXC. To disable password saving, go to Chrome > Passwords and autofill > Google Password Manager > Settings and click the On/Off slider for “Offer to save passwords and passkeys.”.

If you’re like me, a constant barrage of notifications is not just annoying — it’s distracting. Every time a notification pops up, my attention is stolen from whatever it is that I’m doing, which means I have to spend extra time getting back into the groove. If that happens constantly, I struggle to get anything done.

According to recent reports, to that end, I disable notifications in my web browsers, my desktops, and even on the lock screen of my Android phones. I then get to decide when I’m distracted (and it usually happens after I finish a task).

To disable notifications in Chrome, go to Settings > Privacy and security > Site settings > Notifications and check “Don’t allow sites to send notifications.”.

Recent findings suggest that if you allow Chrome to dictate where downloads are saved, you could wind up with a directory full of random things. I like to be the conductor of those downloads and where they are saved for two reasons:.

Sources indicate that for example, I download a lot of .deb and .AppImage files on Linux, and I certainly don’t want them all going into the Downloads directory. I also download a lot of documents and ISO images, neither of which should be saved to Downloads. If I left Chrome as is, all those files would be saved in Downloads, which would not only fill that directory but also make it harder for me to find what I’m looking for. Instead, I tell Chrome to ask me where to save every downloaded file.

To enable “Ask where to save downloads,” go to Settings > Downloads and make sure “Ask where to save each file before downloading” is enabled.
