Sources indicate that stepSecurity, a Seattle-area startup founded by two former Microsoft engineers, has raised a $20M Series A led by Elephant. It protects developers’ laptops, code repositories, package downloads and build pipelines from attackers who plant malicious code in open-source software.

StepSecurity, a Seattle-area security startup, has raised a $20M Series A led by Elephant, GeekWire reported. Runtime Ventures, Inner Loop Capital and SaaS Ventures also put in money, taking its total to $23M.

In a recent development, the company guards the places where software gets built, from developers’ laptops to the systems that test and ship code. Hackers now often hide bad code in free, open-source software. Once it runs, it can steal passwords and keys.

Industry observers note that “A supply chain attack used to take a skilled team. Now one person can vibe code it,” CEO Varun Sharma wrote in a blog post.

The round landed in a busy week. On 17 November, hackers posted two poisoned versions of agent-framework, Microsoft’s Python toolkit for AI agents, which gets nearly 200,000 downloads a month. StepSecurity was among the firms that spotted the code, which stole passwords and keys, BleepingComputer reported.

It has been revealed that tools for coders have been behind other substantial hacks. Binance claims its $6.3B hack started with a fake job interview and a tampered developer tool. Last month, a tampered Claude Code extension reached up to 5,000 Cursor consumers.

Sharma spent about 15 years at Microsoft. Co-founder Ashish Kurmi also worked there before leading security at Uber and Plaid. They started StepSecurity in 2021 after living through the SolarWinds and Codecov attacks.

More than 20,000 open-source projects use its free tool, Harden-Runner. Its researchers also helped track the ChainDrop npm worm in August. StepSecurity says its yearly revenue grew fivefold in both 2024 and 2025, but gave no figures.

Next, it aims to guard the sandboxes where AI agents run code. Worms such as Miasma already target AI coding tools. Rivals are growing too: Belgium’s Aikido became a $1B unicorn in January.
