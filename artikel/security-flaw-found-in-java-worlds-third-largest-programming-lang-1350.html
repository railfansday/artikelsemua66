A cyber-security firm has used artificial intelligence (AI) to uncover a critical flaw in the hugely popular computer programming language Java.

Tech start-up Calif - which recently identified a cyber-security flaw in another language, PHP - found the bug in Java's memory functions.

Java is a popular programming language used by nearly all of the world's top companies such as Apple and Amazon, as well as many banks, hospitals and governments.

It is meant to make the IT world more secure by managing your memory online, said computer scientist Professor Toby Walsh, which is why "this is such an unlikely and serious flaw".

The discovery comes after a string of serious technology issues, including a massive Microsoft outage.

On Tuesday, the US National Security Agency said its internal communications went offline on Tuesday due to a "scheduled routine maintenance".

The NSA did not specify whether its outage was linked to the identified Java bug.

Apple also reported multiple services suffered full outages due to an internal enhancement, while a network failure grounded all flights in the US.

US Secretary of State Marco Rubio said there was "zero evidence" the incidents were related.

With the help of AI, Calif discovered a serious security vulnerability called Java4Shell, which allowed an adversary to remotely execute unwanted commands to Java's memory system.

In this case, the adversary was OpenAI's recently-released model GPT-6 Cyber, which is not yet available to the public.

But there are fears hackers could now identify the bug if the flaw isn't fixed.

Oracle, the owner of Java, has not acknowledged the bug, but released a "critical patch update" on Tuesday, which it said contained security vulnerability fixes.

At this stage it is unclear if any platforms or companies have been affected by the latest incident.

But the Java flaw remains a huge concern for cyber-security experts, who say overloading a system's memory is one of the most common ways for hackers to exploit or crash a system.

The BBC has contacted Oracle for comment.

US National Security Agency's classified internal network reportedly goes offline.

Nearly every critical sector, including banking, national security systems, aviation and telecommunications, relies on Java.

First released in 1995, the programming language and computing system is now the "beating heart of the modern economy", Calif said in its investigation.

One of its main functions is to manage and protect memory for you, Walsh, a leading researcher in AI, told the BBC.

The serious flaw could comprise "critical financial systems, customers and organisation's data," cyber-security expert Dr Pedram Hayati mentioned.

In Australia alone, almost every bank uses Java for managing critical transaction data, Hayati added.

The latest incidents have exposed how nearly every critical sector - including national security systems, aviation and telecommunications - relies on legacy infrastructure online.

Earlier this week, thousands of customers at major US banks, including JP Morgan Chase, Wells Fargo and Bank of America, reported trouble accessing services.

The Java discovery follows a critical cyber-security flaw identified in the PHP programming language, also identified by Calif.

PHP is the code that websites like Wikipedia use to collect information and present it in a way you can read on the web.

Surrey Centre for Cyber Security Prof Alan Woodward mentioned the PHP flaw affected some 30 million websites, leaving them vulnerable to malicious attacks.

At the time, website owners were urged to check if their sites were affected and, if so, they were told to install updates to patch the problem or consider going offline.

The PHP flaws went undetected for at least a decade, which Walsh mentioned is similar to what has happened with Java.

"It's been hiding in plain sight for 12 years", he said.

"AI is now exposing more flaws much more quickly," Walsh said including ones that may have been so obscure and difficult that humans could not have discovered them alone.

Earlier in November, OpenAI president Greg Brockman confirmed his manufacturer was pivoting 25% of its staff to focus on cyber-security demands.
