📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

OpenAI is launching ChatGPT Wallet, which it states is “setting a latest bar for secure payments by agents.”.

ChatGPT Wallet works with OpenAI’s “dots” agent feature and includes a partnership with American Express, MasterCard, and Visa. Here’s how it works.

OpenAI notes ChatGPT Wallet is the “first wallet that lets agents pay without access to customers’ actual card details and that requires a security check for every purchase, while also preserving existing card rewards and protections for eligible disputes.”.

“We’re starting with limited availability to ChatGPT Pro consumers,” OpenAI explains, “so we can learn from real-world use and work with businesses, banks, and payment networks to improve compatibility and reliability.”.

The feature won’t work with websites that block agents, however, which has increasingly become an concern online.

In a recent development, before each purchase, the user reviews the items, total, and selected card, then approves it with a security check such as Face ID or a fingerprint scan. Each approval creates a clear record of the purchase the user authorized the agent to make.

After the user approves, the payment network provides a payment token—a substitute for the user’s actual card details—with a card number, security code, and expiration date. The payment is charged to their selected card without ChatGPT Wallet sharing their actual card details with the business or agent.

You can read more about ChatGPT Wallet and how it works here.

The manufacturer emphasizes that payments are secure, card info isn’t shared with your dot or merchants, and that you’re in control of purchases.
