It has been revealed that we’re aggressively pursuing all pathways to reduce impact. As a precaution, we’ve paused all deployments and configuration changes while we review recent changes for any correlation to this event. We’ve determined that the elevated load isn’t driven by an overall increase in traffic, but by a large number of servers being unexpectedly unavailable, which is shifting load onto the remaining infrastructure. We’re investigating what’s causing these servers to become unavailable while we work to safely return them to service.
